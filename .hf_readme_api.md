# Somnia — API

API FastAPI de classification des stades de sommeil (EEG, 30 s) et de détection
d'apnée (ECG, 60 s). Documentation interactive : `/docs`.

**Projet de recherche et de formation. Ce n'est pas un dispositif médical : aucune
sortie ne doit servir à un diagnostic.**

Les signaux de démonstration proviennent exclusivement des bases publiques PhysioNet
(Sleep-EDF, Apnea-ECG). Aucune donnée SHHS n'est présente ici.

Code source, résultats et limites : https://github.com/marinedde/somnia

Ce fichier est versionné dans le dépôt (`.hf_readme_api.md`) et déployé par la CI.
